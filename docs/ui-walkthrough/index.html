Cách dùng và giới hạn

Nhấn liên kết sẽ mở trạng thái mới trong tab hiện tại. Back hoặc reload không khôi phục phần vừa sửa; hãy bắt đầu lại checkpoint nếu cần reset.

Đây là preview thiết kế có tương tác và state trong bộ nhớ tab. Chưa có đăng nhập, upload/parser, AI, lưu server hoặc xuất PDF thật. Gói này chưa được kiểm thao tác trực tiếp trên Chrome.
