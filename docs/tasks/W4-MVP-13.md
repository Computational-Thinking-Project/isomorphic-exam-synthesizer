Nếu đã chạy và hành vi sai, ghi `FAIL`, giữ bằng chứng, dừng các bước phụ thuộc và chuyển đúng owner. Đổi candidate, config, prompt hoặc ledger thì ghi run ID mới và kiểm lại phần bị ảnh hưởng.

Sau xác nhận của Duy, bàn giao bản summary, ma trận, run IDs và SHA/config/ledger cho Đạt/W4-MVP-21.
