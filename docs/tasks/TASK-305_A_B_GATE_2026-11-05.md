## Root causes và thay đổi

1. Receipt đọc `Any | None` như dict gây 5 mypy errors. Parser thu hẹp dict/list/field types trước khi hash metadata, không cast/suppression; thêm malformed scalar/list0/2/nested/unhashable ID/bool/string count/missing fields. Contract tiếp tục fail-closed.
2. SQL `\s` theo locale khác Python Unicode whitespace: `Chọn\u00a0A` được Python đổi sang B nhưng SQL giữ A, từ chối output hợp lệ. SQL dùng tập whitespace Unicode của Python, gồm C0 separators; giữ SQL solution guard độc lập vì payload owner không là integrity proof. Corpus 4,501 comparisons qua helper thật.
3. Uppercase session UUID hợp lệ bị receipt lowercase mismatch sau commit. Normalize tại đầu shuffle service; W kiểm HTTP qua PostgreSQL.
4. SQL kiểm snapshot containers/type identity trước JSON functions; malformed UUID/cast/overflow thành domain input error, vẫn rollback, không success giả.
5. Post-write guard cũ chưa re-read mọi display/metadata. Thêm re-read canonical/display/seed/permutations, metadata rowcount và count finalized thực. Fault tests ép exception, suppress UPDATE và silent corruption; assert đúng loại error/full rollback.
6. Thay ba sleep-based assertions ở test cũ bằng `pg_blocking_pids`. Revert test dùng lineage thật: SQL006 phục hồi root approved/ready và đổi current ID, nên request cũ bị STALE_INPUT; không giả định Revert luôn làm not-ready.

Không rewrite shuffler, canonical validator, SQL006/007, Review/recovery hay matrix. Khi self-review thấy `OrderingPreferences(extra=forbid)` đã chặn unknown fields, bỏ thay đổi validator dư thừa, giữ regression chứng minh behavior sẵn có.
