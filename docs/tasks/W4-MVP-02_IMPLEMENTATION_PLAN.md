- **C1–C3, đã có code và kiểm DB cô lập:** adapter config nhận strict `n_versions` 1–4, modes bỏ qua hoặc `[]` và shuffle mặc định OFF/OFF. Chỉ cho lưu với confirmed canonical snapshot hợp lệ. Gửi neutral `[]` và manifest JSON vào RPC 019, kiểm receipt dựa trên giá trị DB đã lưu.

- **Phạm vi PR:** giữ toàn bộ công việc #64 trên #67 theo thứ tự C4 → C5 khi đủ input → tích hợp và review. Nếu cần tách hoặc đổi phạm vi C5, ghi quyết định với Duy tại #64/#67 trước khi đổi tiêu chí. UI Stage 2/3 thuộc #59 và PR FE liên quan.
